项目新进展 / 海淀区本地分析

完整本地项目现支持2,194个道路名称、33,762个建筑物，新增DeepSeek指令解析、候选路段确认及数据快照复现。实测交大东路500米任务：读取567个附近建筑物，327个相交；此数量对应特定候选路段和数据版本，不代表区内全部建筑物。

本公开体验页仍使用合成样本与本地知识检索，不接入DeepSeek，也不提供海淀区真实数据在线计算。完整功能需在本地运行，地理原始文件与API密钥未公开分发。

任务02 · SPATIAL ANALYSIS

空间分析

描述分析任务

数据：120 个程序生成的建筑矩形 + 1 条示例路。坐标单位为米，非真实地理位置；不对应昌盛路的 510 / 105 验收数据。
能力与统计口径
支持示例路 0–1000 米（不含0）的单距离分析。建筑物与缓冲区有部分相交或边界接触即计入。距离为矩形至道路线段的最短平面距离。分母固定为120。当前不支持高度、人口、预测、任意道路或多步规划。
参数确认与计算　→　结果核对与导出

了解原项目与本体验版的关系

原项目基于 Streamlit、GeoPandas 与 Shapely，支持本地规则或 DeepSeek 参数提取，另有独立 RAG 知识问答入口。此体验页是公开展示用的独立前端，使用合成数据和受限规则，不代表已验证在线大模型或 RAG 效果。原项目的真实数据验收、39项工程回归及30条本地指令评测，请查看仓库材料。
