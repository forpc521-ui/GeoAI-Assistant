这份产品解决什么

在数据已就绪时，帮助使用者选对路段、理解相交建筑物范围、导出清单并找回计算依据。模型负责理解文字，GIS 负责几何与计数。

直接选择道路与距离也是可用路径；自然语言是否更好需对照验证，不能把流程自动化全部归功于 AI。

描述分析任务

数据：120 个程序生成的建筑矩形 + 1 条示例路。坐标单位为米，非真实地理位置；不对应昌盛路的 510 / 105 验收数据。

支持示例路 0–1000 米（不含0）的单距离分析。建筑物与缓冲区有部分相交或边界接触即计入。距离为矩形至道路线段的最短平面距离。分母固定为120。当前不支持高度、人口、预测、任意道路或多步规划。

了解原项目与本体验版的关系

原项目基于 Streamlit、GeoPandas 与 Shapely，支持本地规则或 DeepSeek 参数提取，另有独立 RAG 知识问答入口。此体验页是公开展示用的独立前端，使用合成数据和受限规则，不代表已验证在线大模型或 RAG 效果。当前完整产品的能力与指标以当前 PRD 和 2026-11-11 评测为准；2026-10-18 的工程与规则结果仅作历史基线。
