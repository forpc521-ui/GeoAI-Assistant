# GeoAI Assistant PRD：道路缓冲区建筑物分析 MVP

版本：2026-10-18 求职演示基线；状态：本地闭环已验证，在线模型与真实用户收益未验证。

## 问题与目标用户

目标用户假设是 GIS 初学者、需要做道路周边初步筛选的工程分析人员。他们需要将“道路周边多少米有哪些建筑”转为可解释、可导出、可追溯的结果。该假设来自项目设计，尚无访谈、问卷或真实客户数据支撑。

本期目标：让用户用受约束的文字指令完成参数确认、空间计算、结果检查、导出与历史复现。成功交付单位是一条可核验的分析任务。当前数据不用于工程决策，尚不能证明节省人工时间。

## 范围与优先级

| 优先级 | 用户需要 | 当前实现 | 验收依据 |
|---|---|---|---|
| P0 | 提交道路、距离与对象 | 本地规则或可选 DeepSeek 提取 BufferTask；道路白名单、单距离及操作校验 | test_gis_natural.py |
| P0 | 查看真实计算结果 | 缓冲区、intersects、最短距离；地图和数量同源 | test_gis_real_results.py、test_gis_product_ui.py |
| P0 | 识别无效要求 | 空输入、范围越界、道路不存在、不支持属性/时序/路径任务提示；失败清空旧结果 | test_gis_product_ui.py |
| P0 | 导出与复核 | 汇总/筛选或全量 CSV、缓冲区/相交建筑 GeoJSON | test_gis_product_ui.py |
| P0 | 保留与复现 | 自动保存快照、参数、结果、代码与环境摘要；历史查看、JSON/ZIP、快照重算比对 | test_gis_history.py |
| P1 | 理解结果含义 | 参数、相交边界、分母、来源摘要与待核实项说明 | 界面与产品测试 |
| 旁路能力 | GIS 知识问答 | FAISS + 中文 embedding + DeepSeek，展示检索片段 | 本轮未验证在线回答质量 |

侧边栏由用户选择功能，没有通用 Agent 自动路由。无文件上传、多道路比较、多步工具规划、任意空间任务、人口/高度统计、预测、CAD/BIM 或遥感分析。

## 用户流程与交互契约

详见 UserFlow.md。核心流程为：选择自然语言分析 → 阅读可用道路及口径 → 输入指令与解析方式 → 提交校验 → 使用快照计算并完整保存 → 显示任务编号、地图、表格、统计 → 导出 → 进入历史任务 → 用当时输入重算 → 显示一致/差异报告。

- 有效示例：`分析昌盛路周边500米范围内的建筑物`。支持明确数字的米/公里，也转换“半公里”。
- 当前可用道路由输入数据列出，本基线只有昌盛路；距离要求 0 < d ≤ 5000 米，指令1至500字。
- 本地规则仅支持约定句式；不识别同义句时提示示例或尝试 DeepSeek。DeepSeek 也必须通过相同任务边界校验，不能直接生成结果。
- 新提交先清空旧结果。非法输入不创建任务；执行或保存失败不展示成功结果；刷新、筛选不新增任务。
- 没有 API 密钥时可完整演示本地空间分析；DeepSeek 配置或连接错误给公共提示。

## 结果口径

同名道路要素合并后，在 EPSG:32650 中生成缓冲区。范围内是与缓冲区相交的建筑物，含部分相交和边界接触。范围外是本次输入建筑物的补集；按要素计数。占比分母为本次全部输入建筑物，不是行政区总建筑数；零分母在导出函数中留空。最短距离是建筑几何到合并道路几何的距离，保留两位小数。地图和 GeoJSON 为 EPSG:4326。

汇总 CSV 始终覆盖全部输入建筑；明细随“仅查看相交建筑物”切换。CSV 不含几何，使用 UTF-8 BOM。历史复现使用旧输入和当前程序，归档代码仅供追溯，不自动执行；一致性仅针对本实现比较的图层几何、关键标识、相交标记和距离。

## 非功能需求与限制

本地文件存储，无账号、多租户隔离、线上 SLA 或生产并发保证。保存采用临时目录写完再发布任务目录，文件 SHA-256 用于完整性核查，不是防篡改签名。处理范围受固定投影约束。来源详情见 DataSources.md；尚未确认下载范围是否覆盖整个缓冲区，不能把统计宣传为区域全量。

## 指标与发布门槛

指标分母、真实观测和限制见 Metrics.md。当前发布门槛是：39项工程回归通过；约定句式的正向任务能计算、导出、重载和复现；非法要求明确提示；UI、CSV和空间图层一致。任意自然语言泛化不属于已完成门槛，失败必须保留。

下一轮可验证假设：招募目标用户完成同一任务，记录独立完成率、澄清次数、导出理解错误和任务时间；以手动 GIS 操作为同任务基线。当前没有这些结果。若同义表达成为主要阻碍，先建立独立新增测试集，再比较受约束模型解析与规则引导；不通过修改已有标签提高成绩。
