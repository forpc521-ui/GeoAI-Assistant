# 指标字典与真实验证基线

> 历史基线（2026-10-18）：下文只适用旧昌盛路规则样本。当前海淀区及周边能力见 [当前 PRD](../05_Demo/Portfolio/GeoAI-Assistant_PRD_v2.0_AI产品版.md)，模型与 RAG 指标见 [2026-11-11 评测](../05_Demo/ai_quality_20261111/report.md)，用户收益仍未测。

日期：2026-10-18；范围：昌盛路、510个本地建筑物；开发者编写30条冻结指令，不是外部用户盲测。

| 指标 | 定义/分母 | 本轮观测 |
|---|---|---|
| 整体指令行为正确率 | 参数正确的有效指令或明确拒绝的异常 / 全部30条 | 22/30，73.33% |
| 有效任务参数正确率 | 道路、距离、操作全对 / 全部20条有效指令 | 12/20，60% |
| 标准表达正确率 | 12条标准表达 | 12/12 |
| 同义改写正确率 | 8条同义表达 | 0/8；本地规则均拒绝，保留失败 |
| 异常处理正确率 | 明确拒绝或要求澄清 / 10条异常 | 10/10；连接异常不算正确拒绝 |
| 业务任务成功率 | 解析、参考核对、保存、重载、ZIP校验全部通过 / 全部20条有效指令 | 12/20，60% |
| 闭环通过率 | 业务成功且快照复现与原结果和参考相符 / 全部20条有效指令 | 12/20，60% |
| 已执行任务空间/复现核验 | 已正确解析并执行的12条；条件指标 | 各12/12，不能冒充总体成功率 |
| 工程回归 | unittest六组，含AppTest | 39项通过；不是39名用户或39条独立业务任务 |
| DeepSeek和RAG在线质量 | 本轮未调用真实API | 未验证，不输出准确率 |

核心空间参考结果：300米53个、500米105个、1000米191个；500米总数510，范围外405，范围内20.59%。参考是独立逐建筑距离实现，底层仍共享 Shapely/PROJ，不是测绘真值。

业务延迟为成功任务 n=12，本机单轮P50=425.36ms、P95=786.41ms，包含解析、计算保存、重载和ZIP导出；不含冷启动、页面渲染和复现，不是线上SLA。建议简历省略延迟，避免读者误解为用户完整等待时间。

证据：交付包 `local_evaluation/report.md`、`results.json`、`case_results.csv`、`cases.json`、`reference.json`、`provenance.json` 和 `regression.log`；项目内同步摘要位于 `05_Demo/acceptance_20261018/`。完整失败与样本保留在报告。

尚无：真实用户数/留存/满意度、人工效率提升、收入、用户测试成功率、模型泛化准确率、并发容量。下一轮先收集匿名任务完成情况及手动基线，再设提升目标；不把目标填成成果。
