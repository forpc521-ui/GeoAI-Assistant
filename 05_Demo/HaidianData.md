# 海淀区数据接入与使用（2026-11-11）

已将用户提供的03_Data/raw_documents/osm_test/jing-road.geojson和jing-building.geojson导入持久化本地库。原始GeoJSON未覆盖、未修改，也未公开上传GitHub。原昌盛路验收数据、旧历史记录保留。

## 导入结果

- 道路源文件：38,505个线要素；有效已命名道路保留7,932个、2,194个不同名称。其余30,573个为无可用名称的要素，不进入按名称搜索列表；未发现无效道路几何。
- 建筑物源文件：33,762个多面要素，全部保留；未发现无效几何。建筑物无需有名称。
- 两份源文件坐标系均为EPSG:4326。持久化库使用GeoPackage空间索引及道路名称索引，计算继续用EPSG:32650。
- 两份QGIS元数据标注OpenStreetMap contributors和版权链接；原始下载渠道、日期及行政边界裁剪过程尚未核实，不把导入时间当作数据生产时间。
- 文件包含海淀区周边道路（如东长安街），建筑物范围也小于道路范围，故页面明确标注“海淀区及周边”，不宣称海淀区完整覆盖或仅包含区内要素。若需要严格区内统计，需另提供可信海淀区行政边界再裁剪。

## 使用

1. 打开本地原项目 http://localhost:8501 ，侧边栏选“自然语言空间分析”；当前默认数据范围为“海淀区本地数据包（默认）”。也可打开独立入口 http://localhost:8503 。
2. 输入“分析中关村大街周边500米范围内的建筑物”，点击“解析指令并定位道路”。
3. 确认路段地图、长度和坐标，再点击“执行本地建筑物筛选”。同名不连通道路分为候选，平行车道也可能分开。
4. 可直接通过道路下拉框搜索“学院路”“中关村南大街”“颐和园路”等，再设置距离。
5. 查看统计、地图、CSV/GeoJSON；在任务记录中查看或复现。分析不请求在线地理接口；默认本地规则不消耗 DeepSeek token；可选 DeepSeek 解析在提交时调用 API，见文末。

如需重启独立入口：

```powershell
Set-Location 'D:\GeoAI-Assistant'
& '.\venv\Scripts\python.exe' -m streamlit run '.\04_Code\local_app.py' --server.address 127.0.0.1 --server.port 8503
```

数据只需导入一次，之后保存在03_Data/beijing_library（沿用旧目录名称，不代表北京市域覆盖）。自然语言页不再提供北京在线查询入口。再次导入文件时单文件允许512MB，避免新建筑物文件约220MB被旧200MB默认限制拦截。

## 实际验证

使用真实导入数据、默认第一个中关村大街连通路段（10个道路要素）与500米距离：按缓冲范围包围框读取609个建筑物，其中371个相交、238个在范围外。此分母是附近读取样本，不是海淀区全部33,762个建筑物；CSV明细行数匹配筛选结果。已保存任务并实际复现，几何、距离与统计核验一致。

当前任务：20261111T003149047431_b89f925ff1cc；复现任务：20261111T003149990866_0c26f8254768。改变候选路段时不能沿用这一数量作为预期。

修复了区域道路库中纯数字名称“5”误匹配距离“500”的问题，以及长短道路名重叠误判为多条道路的问题；原不支持任务和多道路校验仍保留。原冻结测试改为显式选择旧验收样本，避免默认数据切换改变旧统计基线。

GitHub Pages仍为独立合成体验版，本次数据及本地功能不等于已发布公网版本。

## DeepSeek指令解析（2026-11-11新增）

自然语言表单增加“海淀区指令解析方式”：默认“本地规则（无需API）”，可改为“DeepSeek（API指令解析）”。自动读取项目根目录.env中的DEEPSEEK_API_KEY，不要求在网页填写密钥。只有提交解析时调用模型，参数为deepseek-chat、temperature=0、输出上限300 token、网络超时30秒、无自动重试。

发送内容为用户指令、任务规则及指令中明确提及的道路名称，不发送建筑物几何或整个道路库。接口返回的道路、距离、操作字段经过原校验；缺少道路、超范围、模型距离与指令不一致及不支持的高度/预测要求会被拒绝。失败明确提示，不静默降级成本地规则。

示例：“帮我看看交大东路附近500米有哪些建筑物”。点击“解析指令并定位道路”，确认候选后再执行本地筛选。若没有改动道路和距离，历史记录保留原始指令和DeepSeek解析方式；手工修改参数则记录为道路选择。建筑物统计、导出和快照复现仍为本地操作，不再次请求模型。

已实际调用DeepSeek成功解析该示例，取得交大东路、500米；此单次请求不是模型准确率或时延承诺。52项既有回归通过，另3项新增测试覆盖模型参数、缩小道路上下文、本地零API调用、不支持任务和错误距离拒绝。界面与任务解析来源使用隔离测试验证，未虚构更多真实模型调用次数。
