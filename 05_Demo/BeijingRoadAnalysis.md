# 北京道路分析扩展

自然语言空间分析页面新增道路数据范围选择：原昌盛路验收样本、本地区域全部已命名道路、导入北京道路与建筑物。

本地区域道路文件含1243个要素、65个不同名称；建筑物仍为原510个局部样本。建筑物未覆盖的区域不能据零结果判定没有建筑物。

选择“导入北京道路与建筑物”时，需要上传配套GeoJSON：道路包含name字段与线几何，建筑物为面几何；两份文件需明确坐标系，并经过覆盖范围和来源核验。当前米制投影仍为EPSG:32650，保持原计算逻辑及适用范围校验。未接入全北京市数据或在线地名搜索。

任务输入方式可选择自然语言指令或选择道路与距离。结构化选择支持胡同等未被原自然语言句式覆盖的道路名称。同名要素会合并，请按区域裁剪文件以避免合并不同地点的同名道路。

执行后仍走原任务快照、结果导出和历史复现流程。临时输入目录按浏览器会话隔离，历史任务保存输入快照。GitHub Pages合成数据体验页未改变，也未发布任何本地原始数据。

使用步骤：启动本地Streamlit → 自然语言空间分析 → 选择数据范围 → 如需则上传配套文件 → 选择任务输入方式 → 提交分析。默认保留旧样本与自然语言入口。
