# GeoAI Assistant 产品需求文档

版本：V2.1｜更新：2026-11-12｜状态：本地可运行原型，开发验证已完成若干链路，用户价值验证待执行。

## 1. 产品摘要

面向有授权基础数据、需要完成单路段周边建筑物清单的 GIS 初学者与工程助理，将任务表达、路段确认、空间筛选、导出与历史复核串联。当前完整产品在本地运行；[公开入口](https://forpc521-ui.github.io/GeoAI-Assistant/demo-v2/)提供合成交互、真实运行视频及已保存模型结果回放，不提供实时 DeepSeek 或真实区域在线计算。

核心价值假设是减少操作组织与结果复核负担，而不是让模型替代 GIS。尚无独立用户访谈、节时或商业效果证据。

## 2. 问题、用户与证据

应用场景面向市政规划院、道路及铁路设计院的前期资料整理，首批验证定位到工程助理的具体筛选任务；不把机构级业务价值当成已验证成果。

目标任务：“确认指定路段，筛选周边指定距离内建筑物，导出清单并说明数据范围”。不把市政规划、铁路设计等专业决策群体笼统当作已验证客户。

已观察：项目在线道路请求反复超时；开发指令的自然改写有规则解析失败；使用者对建筑物总数范围产生疑问。它们支持可靠性、表达覆盖和口径说明的改进，不足以证明市场需求。用户需求强度、发生频率、既有替代工具与使用收益按[验证计划](../../01_Product/ValidationPlan.md)补证。

## 3. 目标与非目标

用户目标：明确能力与数据覆盖，选对路段，得到正确筛选结果和可用文件，之后可复核。

产品目标：先验证独立正确完成与理解，再比较自然语言相对表单的增量；没有营收、增长或生产规模承诺。

非目标：自主多步 Agent、多道路比较、高度/人口/预测、路径规划、拆迁估价、工程安全结论、全北京市或完整海淀区覆盖。RAG 是独立知识辅助，不代替几何计算。

## 4. 当前范围与用户故事

| 用户故事 | 当前实现与验收要求 |
|---|---|
| 我想说出任务，也能直接设参数 | 本地规则或 DeepSeek 提参，直接选道路与距离可用；当前本地页面范围 0.01–5000 米，单路单距；明确不支持任务需拒绝/澄清 |
| 我想知道是不是选对道路 | 同名不连通路段分候选，显示形状、长度与坐标，由用户确认；不能自动把所有同名道路合并 |
| 我想得到可解释结果 | GIS 算数，地图、数量、表格、来源、路段、距离与任务号一致；旧结果标识清楚，不把改参数当已重算 |
| 我想带走与复核结果 | CSV/GeoJSON、任务快照、历史查看与复现；新复现关联原任务，不覆盖原记录 |
| 我想理解 GIS 概念 | BGE＋FAISS 检索至多 3 片段，DeepSeek 回答及来源；资料不足题需说明，不声称自动事实核验 |

当前海淀区及周边数据保留 7,932 个已命名道路要素（2,194 个名称）、33,762 个建筑物。未核实行政边界完整覆盖，建筑范围小于道路范围。旧昌盛路模式为历史验收样本，独立保留。

## 5. 交互、状态与恢复

主流程：查看数据范围 → 选择输入路径 → 解析/设参 → 确认候选 → 执行筛选 → 核对地图与表格 → 导出 → 历史复现。知识问答不自动触发空间任务。

| 状态 | 要求与当前边界 |
|---|---|
| 初始/无库 | 提示可用任务和准备数据，不能用合成数据冒充真实数据 |
| 解析等待 | 明示模型调用；请求超时或无密钥提示恢复方式；无静默降级 |
| 无路/多路/不支持 | 不执行成功任务，提示改写或直接选路 |
| 无附近建筑数据 | 提示覆盖可能不足，不能解释为现实没有建筑 |
| 成功 | 显示实际参数、数据版本、任务编号及统计；更改参数后需再次执行 |
| 计算/保存失败 | 不发布不完整成功结果，允许修正重试 |
| 历史复现 | 读取原快照、跳过模型，新建关联任务并比较结果 |

完整流程见 [UserFlow.md](../../01_Product/UserFlow.md)。当前不是对所有错误均有自动恢复或置信度评分的系统。

## 6. 统计与数据规范

计算采用 EPSG:32650；显示/GeoJSON 为 EPSG:4326。选中的连通候选内合并道路几何再缓冲；建筑面与缓冲区相交即计入，包括边界接触与部分相交。

空间索引按道路缓冲距离加 100 米形成的包围框读取附近建筑。总数、范围外数及占比分母均为此次读取样本，不是全区总体，也不是固定半径总量；不能跨路段直接比较占比。相交建筑物数受数据完整性影响，不等于现实楼栋普查。

CSV 用 UTF-8 BOM；汇总为完整输入统计，明细导出按对应页面当前选择。地图、表格、导出必须对应同一任务；固定 500 米旧页面能力不完全对称。来源、版本、覆盖、输入摘要随任务保存，任务包含几何和本机路径，分享前审阅。

## 7. AI 与系统架构

```text
文本 → 规则或 DeepSeek JSON → 程序校验 → 人工确认路段 ┐
道路/距离直接选择 → 参数校验 ──────────────────────┤
                                                   ↓
本地 GeoPackage 索引 → GIS 缓冲与相交 → 地图/导出/快照 → 历史复现

知识问题 → BGE 向量 → FAISS Top3 → DeepSeek → 回答与检索来源
```

模型只负责语言，不生成几何计数；参数链路不执行模型生成代码。固定任务无需自主规划。DeepSeek 是沿用集成，不声称在成本/速度/能力上胜过其他模型。表单与规则是有效基线，AI 是否值得默认启用需用户对照。

技术模块：`04_Code/app.py` 主入口，`gis_local_ui.py` 本地页面，`gis_local.py` 数据库与候选，`gis_local_parser.py` 模型解析，`gis_natural.py` 约束与 GIS，`gis_history.py` 历史。以仓库实际模块为准，架构图见 [Architecture.md](../../02_Technology/Architecture.md)。

## 8. 功能以外的要求

- 内容：当前能力、示例、口径与失败提示一致，旧材料标日期，回放明确不是实时服务。
- 可访问性：控件有标签，地图以外可看表格与统计；键盘/读屏与跨设备完整验证尚未完成。
- 分析：当前无用户行为埋点；验证期先用匿名观察记录，不宣称上线活跃或转化。
- 运行：本地已验证环境可启动，干净安装尚未验证；地理数据不公开分发，首次导入见 LocalData.md。
- 安全：密钥在本机 `.env`，不进仓库/网页/任务包；模型接收指令、提及道路名或知识片段，空间几何在本地计算。外部 API 仍需数据外传授权。
- 性能：解析超时 30 秒是配置而非时延成绩；尚无生产并发、SLA、容量与账单结论。

## 9. 验证、指标与成功判据

| 层级 | 当前证据 | 不能据此声称 |
|---|---|---|
| 数据与计算 | 中关村大街特定候选 500 米：609 输入、371 相交，保存与重算一致 | 全区完整普查或所有任务均正确 |
| 指令理解 | 同 10 条开发指令：DeepSeek 10/10，规则 8/10，有效 6 条、异常 4 条 | 泛化准确率 100% 或独立用户完成率 |
| 检索与回答 | 20 题，16 可回答；Recall@3 96.88%，Precision@3 35.42%（此口径上限 37.5%）；无依据扩展 1/20 | 事实幻觉率 5% 或 RAG 已优于直接问答 |
| 用户结果 | 未测；计划记录完成、理解、帮助、耗时和路径选择 | 节时、满意度、商业收益 |

最新报告：[2026-11-11 AI 效果评测](../ai_quality_20261111/report.md)。旧 2026-10-18 的 39 项回归与 30 条规则指令仅作历史基线，不与本轮相加作为模型样本量。

领先指标：路段确认、参数校验、正确导出；结果指标：独立正确完成与统计理解；护栏：错误放行、数据范围误解、API 失败与外传风险。对照先冻结输入和标准，保留失败，用户收益未证实时不发布提升数字。

## 10. 顺序、风险与交接

已完成：本地数据与核心流程、部分真实验收、开发模型评测。当前交付：统一材料、真实证据回放、交互预览。下一验证窗口按[计划](../../01_Product/ValidationPlan.md)组织用户任务对照；完成后决定默认表单还是自然语言，再考虑公网完整服务，尚无承诺日期。

风险：用户需求未经验证；数据覆盖与许可来源链待补；小知识库/小开发集泛化有限；模型接口与环境会变；完整服务公开部署需服务端密钥、配额及数据授权，当前未部署。

开发交接：最小改动保留已通过 GIS 与解析；修改前看上述模块与对应测试；验收至少检查正常/不支持任务、候选、CSV/地图一致、原快照重算。新增功能先有用户问题与可验证标准，不以堆叠工具作为完成条件。
